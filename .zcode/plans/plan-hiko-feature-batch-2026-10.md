## V1（1.99.13）：播放周边快赢包 —— 睡眠定时补强 + 媒体通知步长对齐 + 搜索快捷聚焦

三个小改动，互相独立，均无 UI 结构大动。

### 1a. 睡眠定时补强
- 现状：`lib/playback/sleep_timer.dart` 仅 关/15/30/60 分钟 + 播完当前曲停；不持久化。
- 改动：
  - 新增「自定义分钟数」档：定时对话框（`fullscreen_player_screen.dart`）加滑杆或数字输入（1–240 分钟，步进 5；预设三档保留）。
  - 新增「播完当前专辑停止」模式：在 `PlaybackController` 切专辑边界处拦截（与现有"播完当前曲停"同一路径语义），播完最后一轨且处于该模式则停而非按播放模式续接。
- 验收：设 1 分钟倒计时到期淡出停止；「播完当前专辑停止」在专辑边界停下、切歌不触发；Android/macOS 各验一遍。
- 测试：sleep_timer 纯逻辑补自定义时长 + 专辑停止模式两条用例（时钟可注入已具备）。

### 1b. 媒体通知快进/快退同步 seek 步长
- 现状：`lib/playback/audio_handler.dart` 的 fastForward/rewind 固定 ±15s，与设置「快进/快退秒数」不同步。
- 改动：读 `settings_store` 的 seekStep 应用到 media 通知的前进/后退（audio_service 在 Android 侧走 media3 的快进快退动作，需核对 API 支持自定义秒数；若框架只吃固定档，则至少让 `PlaybackController` 收到通知回调时按设置步长执行，并把通知按钮语义对齐）。
- 验收：设步长 30s → 锁屏/通知栏点快进确实 +30s（Android 实机验证为主，macOS 控制中心抽查）。
- 测试：控制器层面步长取值一条单测。

### 1c. 搜索快捷聚焦（桌面）
- 改动：macOS/Windows 全局快捷键 `Cmd/Ctrl+F` 聚焦主界面搜索框（`lib/ui/global_shortcuts.dart` 已有快捷键注册位）；Android 不做（无物理键盘场景收益低，底部导航已直达）。
- 命中高亮本版不做，视 1c 落地后的观感另行裁决（避免搜索框重构连带 FilterAlbumsMemo 缓存键改动）。
- 验收：任意视图下 Cmd+F 光标进入搜索框且弹出键盘焦点；Esc 既有「返回」语义不回归。
- 测试：快捷键注册断言（沿用 global_shortcuts 现有测试样式）。

## V2（1.99.14）：备份/导出（换机迁移）

### 动机
收藏、评分、分类、播放进度、在线收藏索引目前只能靠「打开数据目录」手工搬 `library.json`，Android 端连这个都只是分享单文件。做设置页一键导出/导入。

### 方案
- **备份内容**（单 JSON 文件 `hiko-backup-v1-YYYYMMDD.json`，不做 zip——内容本就全是文本）：
  - `schemaVersion`（向后兼容留门）
  - `library`：library.json 原文快照（含专辑元数据/评分/收藏/genre/续播位置/刮削信息）
  - `categories`：分类表（categories_provider 的 SharedPreferences 数据）
  - `settings`：settings_store 白名单键（外观/音频/在线账号外的行为开关；**不含**自定义背景图等大文件引用、不含本机路径类键）
- **明确不备份**：封面缓存（本地路径跨机无效；在线封面有 URL 可重下）。本地专辑的源文件路径在新机无效是既有限制——导入后提示用户可用既有「清理失效记录」兜底，**导入不自动清理**（避免误删可修复的记录）。
- **入口**：设置 → 数据页，新增「备份导出」「备份导入」两按钮，置于「打开数据目录」附近。
  - Android：导出走 SAF `createDocument`，导入走 `OpenDocument`（platform 抽象 `lib/platform/` 加两个方法，`hiko/android/` 插件补实现）。
  - 桌面：文件保存/打开对话框。
- **导入语义**：整体覆盖（先写临时文件校验 schemaVersion 合法再原子替换 library.json + 重放 settings 键）；二次确认弹窗列明「将覆盖当前库」；导入成功后重载库并回首页。
- **风险/待裁决**：~~在线账号令牌是否入备份~~ **已裁决（2026-10-02）：JWT 令牌不打入备份**，换机重登一次。

### 验收
- macOS 导出 → 清空数据目录 → 导入，收藏/评分/分类/进度/设置全部还原。
- Android SAF 导出到 Download、再导入，同上。
- 损坏/截断的备份文件导入给出明确报错且**不**破坏现有库。

### 测试
- 备份序列化/解析往返单测（含 schemaVersion 不匹配拒绝导入）。
- 导入失败不落盘的守护单测。

## V3（1.99.15）：倍速/增益按专辑记忆 + 本地 DLsite 标签筛选

### 3a. 倍速/增益按专辑记忆
- 现状：倍速（0.5–2.0）与增益是全局持久化，换专辑要手动调。
- 改动：
  - `lib/models/album.dart` 加两个可空字段 `playbackRateOverride` / `gainOverride`（null = 跟随全局；模型往返单测照例补齐）。
  - 生效点收敛在 `PlaybackController` 播放启动/换专辑处：专辑有覆写则应用，无则全局值。全局调速/增益操作**不**清写专辑覆写（避免误固化），提供显式「记住当前设置为该专辑默认」入口。
  - 入口：详情抽屉/在线详情面板的既有菜单区加「此专辑倍速 / 此专辑增益」两项 + 「清除记忆」。
- 验收：专辑 A 记 x1.3 → 播 A 自动 x1.3，切到专辑 B 回全局值；增益同理（三平台链路抽查 Android + macOS）。
- 测试：覆写优先级选择逻辑单测（有覆写/无覆写/清除后）。

### 3b. 本地 DLsite 标签筛选
- 现状：刮削标签只在卡片/详情展示（开关控制），不能筛选。
- 改动：
  - 筛选行加「标签」入口：弹出标签聚合列表（全库遍历刮削标签，按使用数倒序 + 文本过滤；聚合结果按库版本 memo 缓存，复用 FilterAlbumsMemo 的 identity 缓存思路）。
  - 点选标签 → 主网格按「该标签命中」过滤，与现有视图/过滤条件叠加（AND）；再点取消。筛选状态与现有筛选链同源，不另起炉灶。
  - 标签为日文原文，量大：列表顶部放搜索框 + 默认只展开 Top N（其余靠搜索），不做全量平铺。
- 验收：大库（数百张）点标签筛选无卡顿；与「收藏」过滤叠加结果正确；清筛选后网格复原。
- 测试：标签聚合（计数/排序）与叠加过滤的纯逻辑单测。

## V4（1.99.16+）：在线作品整包离线

四版中工程量最大，放最后单独立项，方案开工前再细化并出独立任务书。

### 方案骨架
- **存储**：沿用 `online_audio_cache` 的按作品目录结构；新增「离线保留」集合（作品级标记，set 持久化），该集合内的文件**不参与 LRU 淘汰**、不计入缓存上限统计（单独统计分区）。
- **下载内容**：作品全部音轨 + 配套字幕（LRC/VTT）+ 封面。按文件粒度断点续传（已存在且大小一致即跳过），支持暂停/取消。
- **入口与进度**：在线详情面板加「下载整包」按钮 → 进度条（已完成/总数 + 当前文件）；下载任务列表入口放在线收藏页或设置缓存页（开工时定）。
- **约束**：下载前若作品体积超阈值（如 >500MB）弹确认；Android 蜂窝网络提示一次（记设置不再问）。
- **风险/待裁决**：
  - ~~多子文件夹大型作品的默认范围~~ **已裁决（2026-10-02）**：不做默认全量，由用户自行勾选要下载的内容（作品内文件夹/音轨级选择）。
  - ~~离线作品的播放入口~~ **已裁决（2026-10-02）**：单独加入口访问，首选挂在在线收藏页（如「离线」分区/标签）；不在本地网格露出，避免本地/在线双写。

### 验收
- 下载中型作品 → 飞行模式下完整播放（含字幕）；删除整包后缓存统计回落；LRU 清理不碰离线保留作品。

### 测试
- 断点续传判定（文件存在/大小一致/不一致）纯逻辑单测；LRU 排除逻辑单测。
