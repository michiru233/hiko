## DLsite 标签刮削功能实现方案

### 目标
为每张专辑从 DLsite 作品页刮削标签（来源：同 RJ 号作品），卡片显示前 3 个（超出显示 +N），详情页显示全部。手动触发。

### 1. RJ 号提取（main.js，导入时）
- `scanAlbum` 里用正则 `/RJ\d{5,}/i` 从 `sourcePath` 文件夹名提取（DLsite 下载的标准命名），回退到标题和曲目名
- 存入专辑新字段 `rjCode`（无则 null），随 library.json 持久化

### 2. DLsite 刮削器（main.js 主进程）
- **请求**：Electron `net.fetch`（Chromium 网络栈）请求 `https://www.dlsite.com/maniax/work/=/product_id/{RJ}.html`，走代理 `http://127.0.0.1:7890`（可在设置里改/清空）
- **解析**：正则从 HTML 提取标签列表（实现时用真实页面验证，预留多种选择器/正则回退模式；页面结构有变就加模式）
- **批量 + 限流**：`dlsite:scrape {ids}` IPC，逐个顺序请求，间隔 ~400ms，失败跳过不中断，返回 {scraped, failed} 摘要；每张完成后发 `dlsite:progress` 事件
- **持久化**：刮到的 `tags` 写回专辑对象并保存（saveAlbums 已会持久化整张专辑）

### 3. preload.js
暴露 `scrapeDlsite(ids)`、`onDlsiteProgress(cb)`

### 4. UI（app.js / index.html / styles.css）
- **卡片**：现有标签行下方加一排小标签（青色系，区别于紫色类型标签），最多 3 个 + "+N" 溢出角标；无标签不显示
- **详情侧栏**：显示全部标签 + 小字 RJ 号（便于核对/发现问题）
- **手动触发**：
  - 右键菜单加"刮削 DLsite 标签"（仅当该专辑有 rjCode 时显示）
  - 多选操作条加"刮削标签"按钮（批量）
- **刮削进度条**：复用导入进度条样式，显示"正在刮削 X / Y 张专辑"
- **设置**：数据区块加"刮削代理"输入框（默认 `http://127.0.0.1:7890`），存主进程配置文件

### 5. 测试
- 用代理 curl 验证 DLsite 可达性（当前环境直连被重置）
- 抓真实作品页验证标签解析正则
- 端到端：造一个 RJ 命名的测试专辑 → 右键刮削 → 卡片/详情显示标签
- 用独立 userData 目录测试（不碰真实库）

### 6. 打包
`npm run dist` → 0.25.0

### 说明
- 不新增 npm 依赖（正则解析）；若实现时发现页面结构过于易变，再考虑引入 cheerio
- 失败处理：刮削失败只跳过该专辑，不缓存失败结果（手动触发时自然重试）
- DLsite 数据源自作品页公开信息，请求限速 + 本地缓存，礼貌访问
