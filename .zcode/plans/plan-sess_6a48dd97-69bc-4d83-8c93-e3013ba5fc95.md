# Kikoeru Flutter 重写实施计划

## 已确认决策
- 平台：macOS + Android + Windows（不做 iOS/Web）
- 旧数据：全新开始（不迁移旧 library.json，schema 自由设计）
- 存储：继续 library.json（JSON 整体读写，原子写 + 增量保存）
- 播放：just_audio + audio_service（Android: ExoPlayer + 前台服务通知锁屏；macOS: AVPlayer）
- 版本：从 1.0.0 重启，沿用"每次改动 bump 版本"约定
- 状态管理：Riverpod；Android 原生扫描/SAF 逻辑移植现有 ImportScanner.kt 为 MethodChannel 插件

## 项目结构
仓库内新建 `kikoeru/` 子目录（旧代码保留参考）：
- lib/models/：Album/Track/设置模型（JSON 序列化）
- lib/data/：library_store（原子写+增量保存）、settings_store（shared_preferences）、scanner（桌面扫描）、metadata（audio_metadata_reader + repairText）、cover（≤300px/120KB）、dlsite_scraper（Dart http + 正则移植）
- lib/playback/：playback_controller（队列 + 4 种播放模式 + 进度落盘）、audio_handler（audio_service 集成）
- lib/ui/：screens（库网格/详情/设置/正在播放）、widgets（卡片/播放条/侧栏/多选/右键菜单/Toast/对话框/进度条）、covers（12 种 SVG 兜底封面 CustomPainter）、theme（浅深 + 6 强调色）
- lib/platform/：Android MethodChannel 封装
- lib/utils/：rj 提取、自然排序、repairText、时间格式
- android/：MethodChannel 插件（移植 KikoeruPlugin/ImportScanner 的 SAF 导入、删除、cleanMissing、revealInFolder、openDataDir 分享；删除旧 Media3 前台服务，由 audio_service 取代）

## 分阶段实施（每阶段可运行 + bump 版本）
- M0 脚手架：检查/安装 Flutter SDK → flutter create（macos/android/windows）→ 依赖 → AGENTS.md/README/plan 文档更新 → `flutter run -d macos` 冒烟 → 1.0.0
- M1 数据层：models/library_store/settings_store/utils + 单测（RJ 提取、自然排序、repairText、模型往返）
- M2 桌面导入：file_selector 选目录 → 隔离线程扫描 → 元数据+封面+进度 → 合并入库；用 scripts/create-test-library.js 数据验证（含 Shift-JIS 样例）
- M3 桌面播放：just_audio + 队列 + 4 播放模式 + 播放条 UI + 进度/音量持久化
- M4 桌面 UI 完整：三栏布局、搜索/筛选/排序、主题+强调色、侧栏折叠、⌘K、多选、右键菜单、Toast、确认框、进度条、正在播放视图
- M5 数据操作与刮削：删除（含源文件）、cleanMissing、reveal、打开数据目录、DLsite 刮削+代理+标签展示
- M6 Android：插件移植 → audio_service 后台播放+通知+锁屏 → 移动布局（≤1000px 底部导航/抽屉/全屏详情/长按/系统返回）→ 模拟器 kikoeru_test（zh-CN）验证
- M7 Windows：构建配置、explorer reveal、just_audio_media_kit 接入（本机无法构建验证，保证代码正确性）
- M8 打包发布：图标、macOS dmg、Windows 安装包、Android release APK、README、版本收尾

## 关键移植点
- 4 种播放模式逻辑（app.js:180-225）：列表/单曲/随机（专辑内避免连播）/专辑循环（跨专辑）
- RJ 号提取 `RJ\d{5,}` 全层级 + cleanFolderTitle 剥前缀
- repairText 多字符集打分（Android 保留 Kotlin 原版；桌面 Dart 移植）
- DLsite 刮削正则 + Chrome/120 UA + 400ms 限速 + force + 代理
- 12 种兜底封面形状
- 修复项：封面统一 ≤300px/120KB、每 5 张增量保存、"未听完"改用 totalDuration 判定、播放进度定期落盘

## 已知风险（实施中验证）
1. Flutter SDK 未确认安装（M0 检查，缺失则 brew install --cask flutter）
2. audio_metadata_reader 对 Shift-JIS/GBK 解码需样例验证；不行则 Dart 字节级 repairText，再不行 macOS 走 Swift AVFoundation 通道
3. Windows 无法本机构建验证（just_audio_media_kit 接入，后续 CI/真机）
4. 刮削代理在 http 包的接线需验证（dart:io HttpClient 支持）
5. Android SAF 目录选择必须走自写插件
