# 设置页改造计划书（1.99.58 候选，2026-10-29）

> 用户需求（m00301）：设置页杂糅了很多「以前写的、已经完全用不到」的功能；
> 要求 ① 把这些功能**列出来**由用户取舍 ② 功能**分门别类**，把「从头画到尾」的单页
> 改成**几个抽屉跳转** ③ **先出计划书 + 效果图**，审阅通过后才动代码。

> 本文档只做「清点 + 方案 + 效果图」，**没有修改任何产品代码**。

## 0. 结论先说

现状是 **1 个页面、5 组标题、约 55 行**，一条道滑到底：桌面端一屏放不下要滚动，
移动端要滑 6～7 屏。其中：

- **4 项设置已经是死数据**（字段还在、读写代码在、**UI 里再也看不到或看到了也不生效**）→ 建议本轮删掉；
- **6 处功能重复或低频**（同一份设置有两个入口、或「动作」混进「配置」）→ 建议收进子页/换入口；
- 剩下的 40 余项按域拆成 **8 个抽屉（子页）**，索引页一屏能看全。

效果图见文末 §12（4 张：桌面索引 / 桌面子页 / 移动索引 / 移动子页）。

## 4. 目标结构：1 个索引页 + 8 个抽屉

索引页 = 一屏能看全的 4 个组、8 个条目；点条目 → 子页（带返回）。

```
设置
├─ 通用 ────────────────────────────────
│  ├ 外观与显示    主题 · 配色 · 对比度 · 动效 · 字号        7 行
│  ├ 播放与音频    增益 · 音频输出 · 快进秒数（桌面）         3 行
│  └ 主界面        每行专辑数 · 刮削标签 · 导航栏入口         3 行
├─ 在线 ────────────────────────────────
│  ├ 在线账号      登录 · 歌单 · 同步 · 令牌 · 服务器 · 缓存  6 行
│  └ 在线外观      4 个字号滑杆 · 列数 · 每页条数            6 行
├─ 库 ──────────────────────────────────
│  ├ 库与扫描      音乐目录 · 增量/全量扫描                  3 行 + 目录列表
│  └ 数据与维护    导入 · 整理 · 失效 · 备份 · 路径 · 重置 · 代理  7 行
└─ 关于 ────────────────────────────────
   └ 关于          版本 · 检查更新                          2 行
```

第二层（进子页后还能再进一页）只有两处：
- 主界面 → **导航栏配置**（拖拽排序 + 开关，现在是 7 行拖拽列表，塞在主页会把页面顶长）
- 在线账号 → **缓存明细**（按作品清理，现有 `:1064` 列表）

**每页行数都不超过 7 行**，桌面一屏放下、移动端最多滑 1.5 屏。

## 6. 交互规格

### 6.1 索引页
- 顶部：大标题「设置」（`headlineSmall`），右侧无按钮（移动端左上返回）。
- 组标题：`labelSmall` + letterSpacing 1 + `onSurfaceVariant`（沿用现有 `_sectionHeader`）。
- 条目（新组件 `SettingsIndexTile`）：**高 64dp**，左侧 40dp 圆角容器（`primaryContainer@0.35`）
  内放 20dp 图标，中间标题 `bodyLarge` + 副标题 `bodySmall`，右侧 `chevron_right`。
- 点按：整行可点，水波纹用 `M3E` 的 ink（不自定义）；`Hero` 不做，用默认 `MaterialPageRoute` 转场。

### 6.2 子页
- AppBar：`M3EAppBar`，标题 = 条目名，左侧返回箭头（复用现有 `SettingsPage` 的 AppBar 规格）。
- 内容：沿用现有 `_SettingRow`（72dp 双行）/ `_SettingDropdown` / `_ActionButton` / `M3ESlider`，
  **零重画**——这一版只动结构，不动单行视觉。
- 滚动位置：同一会话内进二级页再返回，索引页保持原滚动位置（`PageStorageKey`）。

### 6.3 两个端
| | 桌面（macOS/Windows） | 移动（Android） |
|---|---|---|
| 入口 | 侧栏底部「设置」/ 菜单栏 | 底栏「设置」格 |
| 索引页 | 独立页（沿用 1.99.32 的路由） | 全屏页 |
| 子页 | 同页内 `Navigator.push`，右侧滑入 | 全屏 push，左侧滑入 |
| 返回 | Esc / 左上箭头 | 系统返回键 / 左上箭头 |

> 备选（§11 Q5）：桌面改成**左索引 + 右内容**的常驻双栏（macOS 系统设置那种），移动仍 push。
> 双栏更「桌面」，但要多维护一个布局分支；本计划默认**两端都 push**（同构，改动最小）。
