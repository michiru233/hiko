# Hiko 音频增益（Audio Gain / 音量放大）实现方案

## 一、方案背景与音质保障原理

### 1. 现状与痛点
- macOS 原生 `AVPlayer` 的音量参数被 Apple 严格硬限制在 `[0.0, 1.0]`（100%），无法直接对小声音频进行超额放大。
- 部分同人音声/ASMR/录音作品录音电平极低，用户若调大系统总音量会导致系统提示音、其他软件声音震耳欲聋。

### 2. 核心技术选型：统一 libmpv 64-bit 浮点音频引擎
- 引入官方 `media_kit_libs_macos_audio`，在 macOS 端与 Windows 端统一使用 `libmpv`（通过 `just_audio_media_kit` 路由）。
- **音质与防破音原理**：
  - `libmpv` 底层采用 64-bit 浮点 PCM 混音，原生支持 `softvol` 增益（支持 100% ~ 300% 线性倍率 / 最大 +9.5dB 增益）。
  - 内置浮点动态限幅保护（Soft-clipping），避免传统整数截断造成的“破音、炸麦、毛刺感”，在清晰放大微弱耳语/人声的同时最大程度保持音质纯净。

## 二、具体实现规划

### 1. 依赖与引擎初始化
- **`hiko/pubspec.yaml`**：
  - 引入 `media_kit_libs_macos_audio: ^1.1.4`。
  - 版本递增至 `1.23.0+26`。
- **`hiko/android/app/build.gradle.kts`**：
  - 同步递增 `versionCode = 26`, `versionName = "1.23.0"`。
- **`hiko/lib/main.dart`**：
  - 初始化配置更新为：
    ```dart
    if (Platform.isWindows || Platform.isMacOS) {
      JustAudioMediaKit.ensureInitialized(macOS: true, windows: true);
    }
    ```

### 2. 数据状态与持久化（`SettingsStore`）
- **`hiko/lib/data/settings_store.dart`**：
  - `AppSettings` 新增字段 `audioGain`（`double`，默认 `1.0`，范围 `1.0` ~ `3.0` / 对应 100% ~ 300%）。
  - 新增持久化 Key `'hiko-audio-gain'`，支持 `setAudioGain(double gain)`。

### 3. 播放控制层联动（`PlaybackController`）
- **`hiko/lib/playback/playback_controller.dart`**：
  - 实现有效音量动态合成：
    $$\text{EffectiveVolume} = \text{Volume} \times \text{AudioGain}$$
  - 在播放曲目切换、音量调节、增益调节时，自动计算并下发 `effectiveVolume`。

### 4. UI 交互设计
- **底栏播放条音量弹窗（`hiko/lib/ui/widgets/player_bar.dart`）**：
  - 在原有的基础音量滑块（0% ~ 100%）下方，新增「音频增益」调节区域：
    - 快速档位切换：`1.0x` (标准/关闭)、`1.5x` (+3.5dB)、`2.0x` (+6dB 翻倍)、`2.5x` (+8dB)、`3.0x` (+9.5dB 极限)。
    - 当增益 > 1.0x 时，底栏音量图标增加醒目增益状态标识（如主色高亮/增益角标），让用户一目了然当前处于放大状态。
- **偏好设置弹窗（`hiko/lib/ui/widgets/settings_dialog.dart`）**：
  - 在设置中增加「音频与增益」选项，可直观调节全局默认增益倍率，并带有功能与防破音说明文案。

## 三、验证与自动化交付流程
1. **本地自动化测试**：运行 `cd hiko && flutter test`，确保既有逻辑全部通过。
2. **构建 Release 封包**：执行 `flutter build macos --release`，并打包为 `hiko-v1.23.0-macos.zip`。
3. **更新记录**：在 `.zcode/plans/plan-hiko-flutter-rewrite.md` 记录 `1.23.0` 里程碑。
4. **Git 与 GitHub Releases 自动发布**：
   - `git add . && git commit -m "1.23.0：新增音频增益放大功能（libmpv 浮点软增益 + 1.0x~3.0x 多档位）" && git push origin main`
   - 使用 `gh release create v1.23.0 ...` 自动发布 Release 并附带下载链接。
