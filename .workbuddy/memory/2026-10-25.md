# 2026-10-25

## Hiko M3E 全量界面重构：研究 + 计划书

**产出**：`.zcode/plans/plan-hiko-m3e-redesign.md`（约 760 行）。

**用户裁决（本次重构地基）**
1. 全量重设计，不做双皮肤。
2. 玻璃拟态整体移除。
3. 技术路线：自研 M3E 层（+`motor` +`material_new_shapes` +`material_color_utilities`
   +`material_symbols_icons`），**不迁 `material_ui`**、不用 `material_3_expressive`。
4. Android 优先，macOS 最大复用；UI 层平台判断 ≤10 处且集中在 `adaptive/`。
5. 动效：性能优先，弹簧只跟离散交互，滚动路径零动画零滤镜。

**关键事实（查证过，可直接引用）**
- Flutter 3.47.0 框架内仍含 `package:flutter/material.dart`，且**没有** M3E API
  （无 `MotionScheme` / `MaterialShapes` / emphasized 字阶）。
- 官方 `material_ui`（flutter.dev，2026-10-20）与框架内 material 是**两套类型**；
  `material_3_expressive` 1.2.0（2026-10-23，48 likes，4.08k 下载）强制依赖它。
- **`dynamic_color` 2.1.0 也依赖 `material_ui`** → 本项目不用它，Android 动态取色
  走自建 MethodChannel 读 `android.R.color.system_accent1_*`。
- `SpringDescription.withDampingRatio(mass, stiffness, ratio)` 可直接映射 M3E token 的
  阻尼比，无需换算。
- Hiko 现状：`lib/ui` 19,449 行 / 40 文件 import material / 8 文件 12 处玻璃 /
  208 处 `Icons.*` / 圆角集中 6~12 / 测试 679 passed 2 skipped / analyze 42 条基线。
- **`theme.dart` 的 `fontFamily: 'DM Sans'` 是空声明**：pubspec 从未打包字体，
  实际一直是系统字体。计划里删除该声明，用系统字体 + M3E 字阶。

## 补充：三件事已裁决（用户授权按 M3E 原则自定）

1. **背景图 → 配色种子**（不铺底、不删功能）。依据 Material You 原始模型：壁纸决定配色、
   壁纸不进应用。设置项改为「配色来源」三选一：跟随系统 / 自选图片 / 预设强调色。
   macOS 读桌面壁纸（`NSWorkspace.desktopImageURL`）当种子，与 Android 动态取色语义对齐。
2. **移除黑胶播放样式**。M3E 不做拟物纹理；且英雄时刻需要「卡片角 16 → 封面角 28」连续形变，
   圆盘会打断。将来要变化只走「形状裁切」（circle/squircle），不做旋转。
3. **分类迁到首页 chip 行**。nav rail 是目的地列表不是可编辑文件树；≤8 出 chip，>8 出 split button 下拉。

方法论（可复用）：**M3E 的表达力来自形状/颜色/字阶/动效四个轴，不来自贴图与拟物。**

## 实施：1.99.26 设计系统层（已开工）

新增 `hiko/lib/ui/m3e/` 12 文件 1,647 行 + 10 个测试文件 1,080 行 / 101 条测试。

**两个偏离计划的技术决定（都更轻）**
1. **零新依赖**：`ColorScheme.fromSeed` 在 3.47 已支持 `dynamicSchemeVariant` + `contrastLevel`
   （内部就是 MCU），不需要 `material_color_utilities`；弹簧用框架自带 `SpringSimulation`，
   不需要 `motor`。首次加 `material_color_utilities` 触发 130 个包连带升级（lock 全变），
   已 `git checkout -- pubspec.lock` 完整回滚。`material_new_shapes` / `material_symbols_icons`
   推迟到真正用到时再加。
2. **不用 `FocusableActionDetector`**：探针实测 3.47 测试环境里 `onShowHoverHighlight`
   一次不触发（原生 `MouseRegion.onEnter` 正常），hover 状态层无法写回归锁 →
   改自组合 `MouseRegion` + `Focus` + `GestureDetector`，顺带补 Enter/Space 键盘激活。

**踩过的两个坑（可复用）**
- `Matrix4.getMaxScaleOnAxis()` 取三轴最大值，`Transform.scale` 的 Z 轴恒 1 →
  断言缩放必须读 `transform.storage[0]`，否则永远得到 1.0。
- `TapGestureRecognizer.onTapDown` 要过 `kPressTimeout`(100ms) 才派发；测试里
  `pump(150ms)` 只触发回调，弹簧动画要到**下一帧**才有第一个 tick，必须再 `pump()` 一次。
