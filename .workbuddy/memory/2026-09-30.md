## 1.99.6 安卓端：左划收起播放栏 + 底栏固定「正在播放」

**需求**（用户给安卓截图，两条）：① 仅限安卓端，播放栏加「从左往右划掉取消播放栏」；
② 顺带在安卓底栏加一个「正在播放」按钮，点了进当前歌曲的全屏播放页。

### 裁决（grilling 两轮 11 问，全部记在 plan 1.99.6 章节）

Q1=B 划掉 = 收起 + 暂停；Q2/Q3 点任意歌起播即还原；Q4=A 播放栏手势优先于左边缘呼出抽屉；
Q5=A 跟手位移 + 按比例过阈值消失（不振动）；Q6=A 改造底栏已有「正在播放」格为全屏播放页按钮、
同时从设置可选项移除它；Q7=A 没在播时置灰但仍占位；Q8=A 还原 = 任何一次「暂停→播放」；
Q9=A 进全屏播放页本身不还原；Q10=A 只做 `isMobile` compact 布局；Q11=A 两端一起从
`navViewsAll` 删「正在播放」（8→7），安卓底栏在「设置」左侧固定一格、关不掉。

### 落地

- `player_bar.dart`：`onDismiss`（null 就不套 `Dismissible`，桌面零变化）；套上时
  `startToEnd` + 阈值 0.35 + **`resizeDuration: null`**（源码里只有 null 才会「滑出动画
  一结束就回调 onDismissed」；`Duration.zero` 会多开一根 controller 并进 Dismissible 的
  「dismissed but still in the tree」断言分支）。
- `home_screen.dart`：`_playerBarDismissed` + `_dismissPlayerBar()`（收起 + pause）；
  `ref.listen(select((s) => s.playing))` 认 false→true 跳变还原；抽出 `playerBarVisible`
  统一给播放栏 `if` 与详情抽屉底部留白（118/60）；`_playerBarRect()`/`_isInPlayerBar()`
  让 1.54 左边缘呼出抽屉的手势在播放栏上让位。
- 新增 `widgets/mobile_bottom_nav.dart`（公开 `MobileBottomNav`，从 home_screen 私有类抽出）：
  末尾固定两格，`fits` 从 `+1` 改 `+2`，`playerEnabled` 置灰但占位。
- `settings_store.navViewsAll` 8→7；`sidebar.navViewIcons` 删 `'正在播放'`；设置页「导航栏」
  说明文案补固定两格。存量配置靠 `_normalizeNavViewList` 的白名单过滤自动迁移。
- 新增测试缝 `HomeScreen(debugMobileLayout)`（`@visibleForTesting`，生产永不传）。

### 验证

- **test 595 passed / 2 skipped**（基线 579 + 新增 16）；**analyze 39 条 = 基线**。
- 新增 3 个测试文件（`mobile_bottom_nav_test` 6 条 / `player_bar_dismiss_test` 5 条 /
  `mobile_player_bar_flow_test` 4 条）+ `settings_store_test` 1 条迁移用例。
- **四处验红**（改完即还原）：`+2`→`+1`、撤掉 `pause()`、固定格恒可点、去掉
  `_isInPlayerBar` 让位 —— 各自都让对应用例变红。

  `PlaybackController` 只能写 `_Fake(super._ref)`（基类构造参数名私有）。
