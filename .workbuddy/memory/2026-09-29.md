## 1.99.5 ✕ 热区 / 在线返回键 / 字幕正交 / 分级筛选

**四条需求 + 实测结论**：
1. 社团胶囊 ✕ 点不动 —— **确认是真 bug**：热区仅 **19×19**（13px 图标 + 3px 内边距），
   中心能点、**指尖偏 14px 落空**。
2. 在线带筛选时右滑返回跳去本地专辑页（旧兜底「不在本地音声就切回本地」）。
3. 「字幕筛选只在最新界面可用」的**前提是误判**：`subtitle=1` 查询参数在
   `/api/works`、`/api/tags/{id}/works`、`/api/search/{kw}` **三处都生效**
   （tag222：11/50 带字幕 → 带参 50/50；搜索「おねえさん」6/50 → 7/7）。
4. 分级取值**完备**：`age_category_string` 只有 adult 55442 / general 5886 / r15 1125，
   三者相加 = 全站 62453。`$age:X$` 完美生效，排除式减法也严丝合缝
   （`$-age:r15$` = 61328 = 62453−1125）。**坑：`$age:A$ $age:B$` 是 AND 不是 OR
   （两个正向项 = 0 条），「显示两个分级」必须用排除式**。

**裁决**：Q1=A（只扩 ✕ 热区，图标仍 13px）/ Q2=B（在线内返回键只清筛选、永不切视图）/
Q3=B（字幕放开到所有来源 + 正交保留 + 可关闭标记）/ Q4=B（分级三复选框放进排序下拉，
勾选=显示，全勾或全不勾=不筛）/ Q5=A（在线收藏页不吃这套筛选）。

**实现落点**：
- `online_filter_marker.dart`：`_MarkerCloseButton.hitSize = 36`；承载热区的盒子必须
  同步变高（hit test 不命中父级尺寸之外），故上下内边距归零、左右统一 `left:4,right:0`
  （40px 极端窄屏下 Flexible 压到 0 正好容下 36）。新增 `OnlineSimpleFilterMarker`
  （字幕/分级共用）。
- `home_screen.dart`：`_handleOnlineBack({allowExit})` —— 安卓返回键 true / 桌面 Esc
  isMobile；`在线` 只清筛选回最新榜、干净态才 pop，`在线收藏` 退回 `在线`，其它返回
  false 交回旧兜底。配套 `hasActiveFilter` / `isAtOnlineHome` / `resetToLatest()`。

  新增 `OnlineAgeCategory` 枚举 + `ageCategories` / `ageFilterActive` / `ageTerm` /
  `ageFilterLabel` / `toggleAgeCategory` / `clearAgeFilter` / `clearSubtitleOnly`；
  `_fetch` 把分级词与 creator 词合流，任一非空即全走 search 端点（`/api/works`
  静默丢关键词，和黑名单/creator 同构）。

- 新建 `lib/ui/widgets/online_sort_menu.dart`：`OnlineSortMenu` + `_AgeFilterItem`。

**关键实现选择**：
- **`_AgeFilterItem` 覆写 `handleTap` 而非 `PopupMenuItem(enabled: false)`**：两者都能
  「让菜单不关」，但禁用条目在 M3 下会把文字刷成 onSurface@38% 灰 + 套
  `Semantics(enabled: false)`（复选框明明可用，被念成「已禁用」是错的）。
  复选框包 `IgnorePointer` 当纯指示器，整行由父类 InkWell 接住（避免两个 tap
  recognizer 争抢同一手势切成「开了又关」）。
- **菜单上限 320 → 400**：8 项约 336px，卡 320 会把「全年龄」永久切在折线下
  （320 是硬上限、与屏高无关，桌面同样中招）；400 后手机上生效的仍是 45% 那条。
- 公开组件化的理由同 1.97.1：**可测**。

**测试**：`online_filter_marker_test` +3（36×36 + 偏 14px 仍命中 + 四件套共用）；
新建 `online_sort_menu_test` 5 条；`online_browse_source_test` +6 分级 +3 返回键；
`online_detail_test` 3 处断言改写。**两组新锁都验过红**（hitSize 回 19 → 3 条红；
handleTap 回 super → 3 条红）。

**踩坑（三条可复用）**：
1. 测试窗口默认 600px 高 → 菜单 `maxHeight = 45%×600 = 270`，折线以下的条目 `tap()`
   **落在 ModalBarrier 上把菜单关掉**，报错看起来像「找不到控件」。解法：调
   `tester.view.physicalSize`（1200×1000）。
2. `tester.tap(find.byType(Checkbox))` 必报 hit-test warning（被 IgnorePointer 包着，
   命中的是上层 InkWell）→ 加 `warnIfMissed: false`。
3. `PopupMenuItemState.createState` 返回类型是
   `PopupMenuItemState<T, PopupMenuItem<T>>`（**不是** `State<...>`）；`PopupMenuItem.child`
   是**必填**（即便内容由 `buildChild()` 覆写提供）。`online_sort_menu.dart` 要**同时**
   import `online_models.dart`（`OnlineSort`）与 `online_provider.dart`
   （`OnlineAgeCategory` / `onlineBrowseProvider`）—— provider 文件不 re-export models。
